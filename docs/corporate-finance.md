# 法人企業統計調査 業種別・資本金規模別の財務諸表

| テーブル | 内容 | 主なカラム |
|---------|------|-----------|
| quarterly_statements | 四半期別調査の調査項目（売上高・利益・資産・負債・設備投資・人員など）を業種・資本金規模・四半期ごとに縦に持つ。原数値と季節調整値 | scope / seasonally_adjusted / item_code / item / unit / industry_code / size_code / time / year / quarter / fiscal_year / value |
| annual_statements | 年次別調査の調査項目（付加価値などを含む）を業種・資本金規模・年度ごとに縦に持つ | scope / item_code / item / unit / industry_code / size_code / time / fiscal_year / value |

財務省の法人企業統計調査の時系列データです。営利法人の財務諸表を、業種と資本金規模で集計した推計値です。
四半期別調査は資本金1千万円以上の法人、年次別調査は資本金1千万円未満も含む法人が対象です。

収録期間は、金融業、保険業以外の業種の原数値が1954年4〜6月期・1960年度から、金融業、保険業と
全産業の原数値が2008年4〜6月期・2008年度から、季節調整値が1985年4〜6月期からです。
2008年度からの原数値は毎日の更新で新しい期を追加します。2007年度以前の金融業、保険業以外の業種は、
手元から一度取り込んだものです。四半期の資本金規模のうち10億円以上・1億円以上10億円未満の区分は
1959年7〜9月期からで、それより前は1億円以上だけです。季節調整値は過去の期も改訂されるので、毎日全期間を取り直します。

## 対象業種の範囲（scope）

原典は対象業種の範囲ごとに表が分かれていて、`scope` がどの表の行かを表します。

| scope | 範囲 |
|-------|------|
| nonfinancial | 金融業、保険業以外の業種（業種別・資本金規模別の内訳あり） |
| all_industries | 全産業（金融業、保険業を含む） |
| finance_insurance | 金融業、保険業 |
| banking ほか5つ | 銀行業、貸金業等、金融商品取引業、その他の金融商品取引業等、保険業、その他の保険業 |

調査項目のコードは表ごとに振られています。原数値の `001` は母集団、季節調整値の `001` は売上高です。
`scope`（と `seasonally_adjusted`）で絞ってから `item_code` を使います。金融業、保険業の各業種の表には
売上高が無く、銀行業と保険業は経常収益、ほかは営業収益で持つなど、項目の並びも違います。

全産業（金融業、保険業を含む）の母集団と経常利益は、nonfinancial の全産業（`industry_code` = `104`）と
finance_insurance の和にちょうど一致します。

## 合計と内訳

業種・資本金規模・調査項目のどれも、合計と内訳が同じ列に並びます。絞らずに合計すると何重にも数えます。

- 業種: 全産業（`104`）= 製造業（`108`）+ 非製造業（`144`）。「(集約)」の付いた業種はその下の業種の合計
- 資本金規模（四半期）: 全規模（`26`）= 10億円以上（`25`）+ 1億円以上10億円未満（`24`）+ 1千万円以上1億円未満（`19`）。1億円以上（`23`）は 25 と 24 の合計、`21`・`18`・`20`・`17` は 19 の内訳
- 調査項目: 資産合計と内訳の資産、売上高と売上原価などが並ぶ。比率（％）・回転率（回）・回転期間（月）は足し上げても意味を持たない

金融業、保険業以外の業種の四半期の金額の項目では、業種と資本金規模の恒等式が実測でちょうど成り立ちます。

## 当期末と前期末

貸借対照表の項目は期末残高で、「資産合計(当期末)」と「資産合計(前期末)」が別の項目です。標本調査の
推計値なので、ある期の前期末は前の期の当期末と一致しません（全産業の資産合計で最大2%ほど）。

## 季節調整値

季節調整値（`seasonally_adjusted` = true）は金融業、保険業以外の業種の全規模について、売上高・営業利益・
経常利益・設備投資（ソフトウェアを除く・含む）の5項目だけがあります。同じ期を原数値も持つので、
`seasonally_adjusted` で分けます。業種は全産業・製造業・非製造業の3つで、季節調整値の全産業（`104`）は
「全産業」と名付けられていますが金融業、保険業を含みません。

```sql
-- 全産業（金融業、保険業を除く）の売上高（季節調整値）
SELECT time_name, round(value / 1e6, 1) AS sales_trillion_yen
FROM e_stat.corporate_finance.quarterly_statements
WHERE scope = 'nonfinancial' AND seasonally_adjusted
  AND item_code = '001' AND industry_code = '104' AND size_code = '26'
ORDER BY time DESC;
```

## 期の表し方

四半期の `time` は `YYYYQ`（`20262` = 2026年4〜6月）で、`quarter` は暦年の四半期です。年度の第1四半期は
`quarter` = 2 で、1〜3月期は前の年度に入ります。年度で集計するときは `fiscal_year` を使います。

```sql
-- 2025年度 資本金規模別の経常利益（金融業、保険業以外の全産業）
SELECT size_name, round(value / 1e6, 1) AS ordinary_profit_trillion_yen
FROM e_stat.corporate_finance.annual_statements
WHERE scope = 'nonfinancial' AND fiscal_year = 2025
  AND item = '経常利益(当期末)' AND industry_code = '104'
  AND size_code IN ('25', '24', '19', '16')
ORDER BY size_code DESC;
```
