# 野菜生産出荷統計（vegetable_production）

キャベツ・だいこん・トマトなど41品目の野菜について、作付面積・10a当たり収量・収穫量・出荷量を都道府県別・年産別に収録します。

- `e_stat.crop.vegetable_production`: 87,540行

収録は2003〜2024年産です。地域は全国と47都道府県です。

出典: [農林水産省 作物統計調査 作況調査（野菜）](https://www.e-stat.go.jp/statistics/00500215)

## カラム構成

- year: 年産（2003〜2024）
- crop: 品目（キャベツ、だいこん など）
- season: 作型（`計` が年間の合計。ほかは `春`・`夏秋`・`冬` など）
- subset: うち内訳（`ミニトマト`・`サラダ菜` など）。品目全体の行は NULL
- area / area_name / prefecture_code: 地域コード（`00000` 全国・`XX000` 都道府県） / 地域名 / 都道府県コード（全国は NULL）
- planted_area_ha: 作付面積（ha）
- yield_kg_per_10a: 10a当たり収量（kg）
- harvest_t: 収穫量（t）
- shipment_t: 出荷量（t）

## 群馬県と茨城県のキャベツの収穫量

```sql
SELECT year, area_name, harvest_t
FROM e_stat.crop.vegetable_production
WHERE crop = 'キャベツ' AND season = '計' AND subset IS NULL
  AND area IN ('10000', '08000')
ORDER BY year, area
```

群馬県は2003年産の200,000tから2024年産の271,700tへ、茨城県は87,000tから98,000tへ増えています。群馬県はほとんどが夏秋キャベツ（2024年産は253,700t）で、茨城県は春と冬が中心です。作型ごとに見るときは `season = '計'` を外して `season` で並べます。

## 計と作型を一緒に足さない

1つの品目に `計` と作型の行が並びます。作型を足すと計になるので、品目の年間の量は `season = '計'` だけを見ます。`subset` が入る行は内数なので、品目の量を比べるときは `subset IS NULL` に絞ります。

## 主産県だけを調べる年がある

全都道府県を調べるのは2003・2004・2007・2010・2013・2016・2022年産だけで、それ以外の年産は品目ごとの主産県だけを調べます。調べていない県の値は NULL です（0 ではありません）。そうした年産は都道府県の値を足しても全国になりません。全国の値は全国の行（`area = '00000'`）を使ってください。

## 収録範囲の例外

- 2003年産は、2004年産の表に前年産として載る値です
- みずなは2010年産から、グリーンピースは2013年産から、温室メロンは2005年産からです
- やまのいもと加工用トマトは2023年産までです
- 原典の「…」「－」「X」「nc」はどれも NULL になり、区別できません
