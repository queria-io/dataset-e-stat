# 野菜生産出荷統計（vegetable_production）

キャベツ・だいこん・トマトなど41品目の野菜について、作付面積・10a当たり収量・収穫量・出荷量を都道府県別・年産別に収録します。

- `e_stat.crop.vegetable_production`: 87,492行

収録は2003〜2024年産です。地域は全国と47都道府県です。

出典: [農林水産省 作物統計調査 作況調査（野菜）](https://www.e-stat.go.jp/statistics/00500215)

## カラム構成

- year: 年産（2003〜2024）
- crop: 品目（キャベツ、だいこん など）
- season: 作型（`計` が年間の合計。ほかは `春`・`夏秋`・`冬` など）
- subset: うち内訳（`ミニトマト`・`サラダ菜` など）。品目全体の行は NULL
- area / area_name / prefecture_code: 地域コード（`00000` 全国・`XX000` 都道府県） / 地域名 / 都道府県コード（全国は NULL）
- planted_area_ha: 作付面積（ha）
- yield_kg_per_10a: 10a当たり収量（kg）
- harvest_t: 収穫量（t）
- shipment_t: 出荷量（t）

## 群馬県と茨城県のキャベツの収穫量

```sql
SELECT year, area_name, harvest_t
FROM e_stat.crop.vegetable_production
WHERE crop = 'キャベツ' AND season = '計' AND subset IS NULL
  AND area IN ('10000', '08000')
ORDER BY year, area
```

群馬県は2003年産の200,000tから2024年産の271,700tへ、茨城県は87,000tから98,000tへ増えています。群馬県はほとんどが夏秋キャベツ（2024年産は253,700t）で、茨城県は春と冬が中心です。作型ごとに見るときは `season = '計'` を外して `season` で並べます。

## 計と作型を一緒に足さない

1つの品目に `計` と作型の行が並びます。作型を足すと計になるので、品目の年間の量は `season = '計'` だけを見ます。`subset` が入る行は内数なので、品目の量を比べるときは `subset IS NULL` に絞ります。

## 主産県だけを調べる年がある

全都道府県を調べるのは2003・2004・2007・2010・2013・2016・2022年産だけで、それ以外の年産は品目ごとの主産県だけを調べます。調べていない県の値は NULL です（0 ではありません）。そうした年産は都道府県の値を足しても全国になりません。全国の値は全国の行（`area = '00000'`）を使ってください。

## 収録範囲の例外

- 2003年産は、2004年産の表に前年産として載る値です
- みずなは2010年産から、グリーンピースは2013年産から、温室メロンは2005年産からです
- やまのいもと加工用トマトは2023年産までです
- しょうがの2004年産は、原典の表の列がずれていて前後の年とつながらないため収録していません
- 原典の「…」「－」「X」「nc」はどれも NULL になり、区別できません

## 補足: 作物統計調査 都道府県別の野菜の作付面積・収穫量・出荷量（crop スキーマ）

| テーブル | 内容 | 主なカラム |
|---------|------|-----------|
| vegetable_production | 野菜41品目の作付面積・10a当たり収量・収穫量・出荷量。都道府県別・作型別。2003〜2024年産 | year / crop / season / subset / area / area_name / prefecture_code / planted_area_ha / yield_kg_per_10a / harvest_t / shipment_t |

農林水産省の作物統計調査 作況調査（野菜）の確報「野菜生産出荷統計」のうち、都道府県別の
作付面積・10a当たり収量・収穫量・出荷量の表です。年産・品目・作型・地域（全国と47都道府県）ごとに1行で、87,492行です。

1品目に `計` と作型（春・夏秋・冬 など）の行が並び、`subset` が入る行は「うち」の内数です。
品目の年間の量は `season = '計' AND subset IS NULL` で見ます。

#### 表の形が年代で違う

e-Stat の表は年代で3通りに分かれます。平成16年産と令和元年産は全品目で1表、平成17〜30年産と令和2年産は
1品目1作型1表（品目と作型は表題にしか無い）、令和3年産以降は1品目1表で作型が項目名の接頭辞に入ります。
地域コードも年代で変わる（茨城が 08000 → 1020、N0001 が関東農政局 → 全国）ので、パイプラインは地域を
名前から当てて標準地域コードを振り直しています。

## 補足: crop.vegetable_production

収録は2003年産〜2024年産の22年産、87,492行、41品目。
2024年産の全国の収穫量はばれいしょ 2,295,000t、キャベツ 1,294,000t、たまねぎ 1,126,000t の順。
キャベツの収穫量は群馬県が2003年産 200,000t → 2024年産 271,700t、茨城県が 87,000t → 98,000t。
作型を足すと計になる（公表の丸めで全国のキャベツは最大600tずれる）が、計と作型を一緒に合計すると二重に数える。
subset が入る行は「うち」の内訳（トマトのうちミニトマト、レタスのうちサラダ菜 など）で、同じ品目・作型の subset IS NULL の行の内数。
キャベツで値のある都道府県は全国調査の年が47、2024年産が36。
調べていない県が混ざる年産は、都道府県の値を足しても全国にならない。
主産県だけの年産の全国の値は、調べた県の結果から全国分を推計したものなので、全国の値は全国の行（area = '00000'）で見る。
原典の「…」（事実不詳・調査を欠く）・「－」（事実のないもの）・「X」（秘匿）・「nc」（計算不能）はどれも NULL になり、区別できない。
2003年産は、2004年産の表に前年産として載る値（2003年産の都道府県別の表は上位5位しか無い）。
やまのいもは2024年産の表が無く2023年産まで、加工用トマトも2023年産まで。
area は標準地域コード（5桁、都道府県は XX000）で、census_municipality・school_health などと同じ体系。
全国農業地域・農政局の行は収録しない。
