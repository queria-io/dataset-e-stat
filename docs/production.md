# 経済産業省生産動態統計 品目別の生産・出荷・在庫（月次）

| テーブル | 内容 | 主なカラム |
|---------|------|-----------|
| monthly | 月報の統計表（確報）。月 × 調査票 × 品目 × アイテム（生産数量・販売金額・月末在庫など）の値。2022年1月〜 | time / form_code / form_name / product_code / product_name / item_name / unit / value |

経済産業省生産動態統計の月報のうち、統計表（確報）の実数表です。鉄鋼・非鉄金属・機械・化学・
窯業・紙・繊維・石油製品などの約110の調査票、2,200品目について、生産・出荷（販売）・在庫・受入・
消費・従事者数などを月ごとに持ちます。2022年1月分から統計表の形がそろったので、そこから収録して
います。毎日の更新で、2022年からの年ごとの最新のファイルを取り直して置き換えます。

## 品目とアイテム

1行が「調査票 × 品目 × アイテム × 月」の値です。品目番号は調査票の中の番号なので、`form_code` と
組で使います。アイテム（`item_name`）の名前と並びは調査票ごとに違い、単位もアイテムごとに違います
（t・kl・台・個・千円・人 など）。アイテムや単位をまたいで足さないでください。

合計・中間計の品目と内訳の品目が同じ列に並びます。品種振替・投入（石油製品）は負の値になることが
あります。秘匿の値（X）は NULL です。

```sql
-- 2026年8月の自動車の生産数量
SELECT product_name, unit, value
FROM e_stat.production.monthly
WHERE time = '2026000808' AND form_code = '2400' AND item_name = '生産数量'
ORDER BY product_code;
```
