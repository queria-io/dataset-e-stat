# 人口動態調査（vital_statistics）

出生・死亡・死産・婚姻・離婚の数を、都道府県・市区町村ごとに年で収録します。出生は母の年齢別、死亡は年齢別と死因別にも見られます。

- `e_stat.vital_statistics.vital_events`: 出生・低体重児の出生・死亡・乳児死亡・新生児死亡・死産・周産期死亡・婚姻・離婚（19,628行）
- `e_stat.vital_statistics.births_by_mother_age`: 母の年齢（5歳階級）別の出生数（194,280行）
- `e_stat.vital_statistics.deaths_by_age`: 年齢（5歳階級）別の死亡数（428,076行）
- `e_stat.vital_statistics.deaths_by_cause`: 死因（選択死因分類）別の死亡数（719,946行）

収録は2015〜2024年です。日本にいる日本人の出生・死亡などを、住所のある地域で数えます。

出典: [厚生労働省 人口動態調査](https://www.e-stat.go.jp/statistics/00450011)

## ほかの表との違い

[SSDS の市区町村の表](/cookbook/e_stat/a-population)にも出生数・死亡数・婚姻件数・離婚件数がありますが、2023年までです。乳児死亡や死産、年齢別・死因別の死亡数はありません。住民基本台帳（`resident_registry`）の出生・死亡は外国人を含む届出の数で、この表とは数え方が違います。

## カラム構成

4表に共通の列です。

- year: 年（2015〜2024）
- area_code / area_name: 標準地域コード（5桁） / 地域名
- area_kind: 地域の粒度（下の「地域の粒度」）
- prefecture_code: 都道府県コード（全国・外国・不詳は NULL）

vital_events は births（出生数）・deaths（死亡数）・infant_deaths（乳児死亡数）・marriages（婚姻件数）などを1行に持ちます。ほかの3表は区分の列（mother_age_class・age_class・cause_name など）と、男女別の数（births_male・deaths_female など）を持ちます。

## 札幌市の出生数と死亡数

```sql
SELECT year, births, deaths, marriages
FROM e_stat.vital_statistics.vital_events
WHERE area_code = '01100'
ORDER BY year
```

札幌市の出生数は2015年の14,589人から2024年の9,586人へ減り、死亡数は17,523人から24,576人へ増えています。

## 地域の粒度

`area_kind` で粒度を見分けます。絞らずに合計すると同じ人を何度も数えます。

vital_events:

- `prefecture`（都道府県）だけで日本全域を1回覆います
- `municipality`（政令指定都市以外の市町村と東京都の特別区）と `designated_city`（政令指定都市）の組でも1回覆います
- `ward`（政令指定都市の区）は `designated_city` の内訳です

births_by_mother_age・deaths_by_age・deaths_by_cause:

- 政令指定都市そのものの行はありません。日本全域を1回覆うのは `prefecture` か、`municipality` と `ward` の組です
- 死亡の2表は `nationwide`（全国）・`foreign`（住所が外国）・`unknown`（住所が不詳）の行も持ち、全国は都道府県・外国・不詳の和です。出生の表は全国の行を持たないので、都道府県を足します

`area_code` は各年の標準地域コード（5桁）のままで、6桁の全国地方公共団体コードとは別体系です。たとえば富谷市は2015年が富谷町（04423）、2016年からが富谷市（04216）です。浜松市の区は2024年の再編で 22138〜22140 になりました。

## 死因の段

`deaths_by_cause` は総数（`cause_level = 'total'`）・死因（`cause`）・その内訳（`subcause`、悪性新生物の部位など）・再掲（`restatement`）が同じ列に並びます。選択死因分類は主な死因だけを選んだ分類なので、`cause` を足しても総数にはなりません。

```sql
SELECT cause_name, deaths, deaths_male, deaths_female
FROM e_stat.vital_statistics.deaths_by_cause
WHERE year = 2024 AND area_kind = 'nationwide' AND cause_level = 'cause'
ORDER BY deaths DESC
LIMIT 5
```

悪性新生物と高血圧性疾患は2017年から分類が変わりました。2016年までは `Se02`・`Se15`、2017年からは `Se022017`・`Se152017` の行です。年で続けて見るときは2つのコードをつなぎます。

## 0 と NULL

原典の「-」（該当なし）は 0 です。男の子宮の悪性新生物（`Se12`）だけは原典が「・」（あり得ない項目）なので、`deaths_male` が NULL です。

## 補足: 人口動態調査 市区町村別の出生・死亡・死因（vital_statistics スキーマ）

厚生労働省 人口動態調査 人口動態統計（確定数）から作った4表です。収録は2015〜2024年で、
e-Stat のデータベースにある市区町村別の表がこの10年だけのためです。日本における日本人の
事象を住所地で数えます。

| テーブル | 内容 |
|---------|------|
| vital_events | 出生・低体重児の出生・死亡・乳児死亡・新生児死亡・死産・周産期死亡・婚姻・離婚（年 × 地域1行） |
| births_by_mother_age | 母の年齢（5歳階級）別・子の性別の出生数（年 × 地域 × 母の年齢10区分） |
| deaths_by_age | 年齢（5歳階級）別・男女別の死亡数（年 × 地域 × 年齢22区分） |
| deaths_by_cause | 死因（選択死因分類）別・男女別の死亡数（年 × 地域 × 死因） |

#### 地域の粒度

area_kind で粒度を見分けます。vital_events は都道府県（prefecture）・政令指定都市
（designated_city）・それ以外の市町村と特別区（municipality）・政令指定都市の区（ward）を持ち、
日本全域を1回覆うのは `prefecture` か `municipality` と `designated_city` の組です。
ほかの3表は政令指定都市そのものの行を持ちません。日本全域を1回覆うのは `prefecture` か
`municipality` と `ward` の組です。死亡の2表は全国（nationwide）・住所が外国（foreign）・
不詳（unknown）も持ち、全国は都道府県・外国・不詳の和です。母の年齢別の出生の表は全国の行を
持たないので、都道府県を足します。原典の市部・郡部などの
集計行は持ちません。

area_code は code.municipality と同じ標準地域コード（5桁）で、各年のコードのまま入ります。
原典の政令指定都市の行は独自のコード（札幌市 01010 など）なので、標準地域コード
（01100）に直してあります。

```sql
-- 市区町村の出生数の 2015年→2024年 の変化（全域を覆い、重複しない）。
-- area_code は各年のコードなので、途中でコードが変わった市（富谷市・那珂川市）は
-- 2015年と2024年が別の行に分かれる
SELECT area_code, area_name,
       MAX(births) FILTER (WHERE year = 2015) AS births_2015,
       MAX(births) FILTER (WHERE year = 2024) AS births_2024
FROM e_stat.vital_statistics.vital_events
WHERE area_kind IN ('municipality', 'designated_city')
GROUP BY area_code, area_name
ORDER BY births_2024 DESC
LIMIT 10;
```

#### 足せる行と足せない行

原典の「-」（計数のない場合）は0にしてあります。男の子宮の悪性新生物（`Se12`）だけは原典が
「・」（統計項目のあり得ない場合）なので、deaths_male が NULL です。

この4表は毎日の更新（CI）では e-Stat から取らず、手元で1回だけ取り込んでいます
（下の「手元で1回だけ取り込む統計表」）。

## 補足: vital_statistics.births_by_mother_age

人口動態調査 人口動態統計（確定数）から、都道府県・市区町村ごとの出生数を、母の年齢（14歳以下・15〜19歳 … 45〜49歳・50歳以上・不詳の10区分）別、子の性別に収録する。
年 × 地域 × 母の年齢で1行。
10区分を足すとその地域・年の出生数になり、vital_events の births に一致する。
原典の年齢の総数の行は二重に数えないよう持たない。
地域は都道府県・市町村と特別区・政令指定都市の区が同じ表に並ぶ。
全国・住所が外国・不詳の行は原典に無いので、全国の値は都道府県を足す。
政令指定都市そのものの行は無いので、市の値は vital_events の designated_city の行を使う（code.municipality は現行のコードだけなので、2023年までの浜松市の区 22131〜22137などは当たらない）。
出典: 厚生労働省 人口動態調査 人口動態統計 確定数「出生数，都道府県・市区町村・性・母の年齢（５歳階級）別」（統計表 0003412062）。

## 補足: vital_statistics.deaths_by_age

人口動態調査 人口動態統計（確定数）から、全国・都道府県・市区町村ごとの死亡数を、死亡者の年齢（0〜4歳 … 95〜99歳・100歳以上・不詳の22区分）別、男女別に収録する。
年 × 地域 × 年齢で1行。
22区分を足すとその地域・年の死亡数になり、vital_events の deaths に一致する。
原典の年齢の総数と0〜4歳の各歳の行は二重に数えないよう持たない。
0歳の死亡はvital_events の infant_deaths にある。
地域は全国・都道府県・市町村と特別区・政令指定都市の区と、住所が外国・不詳の行が同じ表に並ぶ。
政令指定都市そのものの行は無いので、市の値は vital_events の designated_city の行を使う（code.municipality は現行のコードだけなので、2023年までの浜松市の区 22131〜22137などは当たらない）。
出典: 厚生労働省 人口動態調査 人口動態統計 確定数「死亡数，都道府県・保健所－市区町村・性・年齢（５歳階級）別・市区町村別」（統計表 0003412064）。

## 補足: vital_statistics.deaths_by_cause

人口動態調査 人口動態統計（確定数）から、全国・都道府県・市区町村ごとの死亡数を、選択死因分類（悪性新生物・心疾患・肺炎・老衰・不慮の事故・自殺など）別、男女別に収録する。
年 × 地域 × 死因で1行。
cause を足しても総数にはならない（選択死因分類は主な死因だけを選んだ分類で、その他の死因の行が無い）。
subcause はcause の内訳、restatement はほかの行の再掲なので、一緒に足すと二重に数える。
悪性新生物（Se02）と高血圧性疾患（Se15）は ICD-10 の改正で2017年から分類が変わり、2016年までは Se02・Se15、2017年からは Se022017・Se152017 の行になる。
年で続けて見るときは2つのコードをつなぐ（同じ年に両方の行が並ぶことは無い）。
地域は全国・都道府県・市町村と特別区・政令指定都市の区と、住所が外国・不詳の行が同じ表に並ぶ。
政令指定都市そのものの行は無いので、市の値は vital_events の designated_city の行を使う（code.municipality は現行のコードだけなので、2023年までの浜松市の区 22131〜22137などは当たらない）。
出典: 厚生労働省 人口動態調査 人口動態統計 確定数「死亡数，都道府県・市区町村・死因（選択死因分類）・性別」（統計表 0003412081）。

## 補足: vital_statistics.vital_events

人口動態調査 人口動態統計（確定数）の人口動態総覧から、都道府県・市区町村ごとの出生数・低体重児の出生数・死亡数・乳児死亡数・新生児死亡数・早期新生児死亡数・自然死産数・人工死産数・妊娠満22週以後の死産数・周産期死亡数・婚姻件数・離婚件数を年1行にまとめた表。
日本における日本人の事象を、住所地（出生は子の住所、死亡は死亡者の住所）で数える。
地域は都道府県・政令指定都市・市町村と特別区・政令指定都市の区が同じ表に並ぶ。
全国の値は都道府県を足す（住所が外国・不詳の分は含まない）。
那珂川市は2018年から 40231。
浜松市の区は2024年に再編されて 22138〜22140 になる）。
社会・人口統計体系（ssds）の市区町村の表にも出生数・死亡数・婚姻件数・離婚件数があるが2023年までで、乳児死亡・新生児死亡・死産・周産期死亡・低体重児の出生は無い。
住民基本台帳の出生・死亡（resident_registry）は日本人に限らない届出の数で、この表とは数え方が違う。
出典: 厚生労働省 人口動態調査 人口動態統計 確定数「人口動態総覧（件数），都道府県・市部－郡部－保健所－市区町村別」（統計表 0003411564）。
