# 経済センサス 産業大分類別の事業所数・従業者数・売上金額

| テーブル | 内容 | 主なカラム |
|---------|------|-----------|
| establishment_industry | 全国・都道府県・市区町村別、産業大分類別・経営組織別の民営事業所数・従業者数・売上（収入）金額 | area / industry_code / organization_code / establishments / employees / sales_million_yen |
| establishment_mesh_1km | 1kmメッシュ別、産業大分類別の事業所数・従業者数（平成28年経済センサス・縦持ち）。昼間人口の推計が流入側の按分に使う従業者数の元の表 | mesh_code / mesh1_code / cat01 / category / value |
| retail_municipality | 全国・都道府県・市区町村別、小売業の産業中分類別の事業所数・従業者数・年間商品販売額・売場面積 | area / industry_code / establishments / employees / sales_million_yen / floor_area_m2 |
| shopping_district | 商業集積地区（商店街）別、小売業・飲食サービス業・生活関連サービス業の事業所数・従業者数・売上（収入）金額・売場面積 | district_code / district_name / district_level / area / district_type_code / industry_code / establishments / employees / sales_million_yen / floor_area_m2 |

令和3年経済センサス‐活動調査（2021年6月1日現在）の産業横断的集計「売上（収入）金額等」
第2-1表です。国勢調査の census_small_area_industry が常住地ベース（住民がどの産業で働くか）
なのに対し、こちらは従業地ベース（事業所がどの産業か）です。

事業所数の母数がほかの表と違います。全国・全産業の事業所数は 4,870,898 で、事業所に関する
集計の民営事業所数 5,156,063 とは一致しません。売上（収入）金額等の集計は必要な事項の数値が
得られた事業所だけを対象にするためで、ほかの統計表の事業所数と突き合わせる用途には
使えません。

## 総数と内訳

総数と内訳が同じ列に縦に並ぶ軸が3つあります。絞らずに合計すると何重にも数えます。

産業（industry_code）の深さは industry_level に出ています。重複なく全産業を覆うのは
AB（農林漁業）と industry_level = 2 の16区分を合わせた17区分で、その和が AR（全産業）に
一致します。

経営組織（organization_code）は 0（総数）= 1（個人）+ 2（会社）+ 3（会社以外の法人）です。
S1・S2 は内数の別掲なので is_reprint で落とします。

地域（area）は area_level で判別します。

| area_level | 内容 | 地域数 | 事業所数の合計 |
|-----------|------|-------:|--------------:|
| national | 全国 | 1 | 4,870,898 |
| prefecture | 都道府県 | 47 | 4,870,898 |
| municipality | 市・町村・特別区部 | 1,719 | 4,870,898 |
| ward | 政令指定都市の行政区・特別区・境界未定地域 | 199 | 1,537,160 |

特別区は ward に入り、その親「特別区部」（13100）が municipality に立ちます。特別区部には
23区のほかに境界未定地域（13199）も含まれます。

```sql
-- 全国の産業別 事業所数・従業者数（重複なく数える17区分）
SELECT industry_code, industry_name, establishments, employees
FROM e_stat.economic_census.establishment_industry
WHERE area = '00000' AND organization_code = '0'
  AND (industry_code = 'AB' OR industry_level = 2)
ORDER BY establishments DESC;
```

## 売上（収入）金額が無い産業

売上（収入）金額は産業によって調査されておらず、建設業・電気ガス熱供給水道業・
情報通信業・運輸業郵便業・金融業保険業・教育学習支援業・複合サービス事業・
サービス業（他に分類されないもの）は NULL です。内訳の一部が欠けるため、全産業（AR）と
非農林漁業（CR）の売上も NULL になります。事業所数と従業者数は全産業で揃っています。

原典が区分ごとに丸めているため、売上（収入）金額は内訳の和が総数と最大1百万円ずれる
産業があります。

1事業所当たり売上（収入）金額と従業者1人当たり売上（収入）金額は、この表の事業所数・
従業者数で割り直した値とは一致しません（原典の分母が違い、両方が揃う約6.1万行のうち
一致するのは1.4万行未満です）。1事業所当たり従業者数は従業者数÷事業所数に一致します。

```sql
-- 市区町村別 卸売業，小売業の従業者1人当たり売上（万円）
SELECT area_name, employees, sales_per_employee_10k_yen
FROM e_stat.economic_census.establishment_industry
WHERE industry_code = 'I' AND organization_code = '0'
  AND area_level = 'municipality' AND employees >= 10000
ORDER BY sales_per_employee_10k_yen DESC
LIMIT 10;
```

原典が「-」（該当数字なし）・「･･･」（調査していないもの）・「X」（秘匿）の区分は NULL に
なり、3つの意味は区別できません。

出典: 総務省・経済産業省 令和3年経済センサス‐活動調査 事業所に関する集計
産業横断的集計 売上（収入）金額等（第2-1表）。https://www.e-stat.go.jp/

## 小売業の市区町村別の表（retail_municipality）

establishment_industry は卸売業と小売業が1つの大分類（I）にまとまっています。小売業だけの
年間商品販売額と売場面積は、卸売業，小売業に関する集計 産業編（市区町村表）の
retail_municipality にあります。1地域につき小売業計（I2）と中分類6区分（56 各種商品・
57 織物衣服身の回り品・58 飲食料品・59 機械器具・60 その他・61 無店舗）の7行で、
地域の段（area_level）は establishment_industry と同じです。

この集計は管理，補助的経済活動のみを行う事業所・格付不能の事業所などを除くので、全国の
小売業計は事業所数 755,015・年間商品販売額 133兆2,575億円です。同じ調査の総括表
（事業所数 880,031・年間商品販売額 138兆1,804億円）より小さく、売場面積は一致します。

事業所数と従業者数は秘匿が無く、市町村の和が都道府県・全国に一致します。年間商品販売額と
売場面積は事業所が少ない区分が秘匿されて NULL になります（小売業計の年間商品販売額が NULL の
市町村は1,719のうち105）。事業所が無い区分は 0 です。

```sql
-- 市区町村別 飲食料品小売業の年間商品販売額（全域を覆い、重複しない）
SELECT area, area_name, establishments, sales_million_yen, floor_area_m2
FROM e_stat.economic_census.retail_municipality
WHERE area_level = 'municipality' AND industry_code = '58'
ORDER BY sales_million_yen DESC NULLS LAST
LIMIT 10;
```

この表は毎日の更新（CI）では e-Stat から取らず、手元で1回だけ取り込んでいます
（下の「手元で1回だけ取り込む統計表」）。

出典: 総務省・経済産業省 令和3年経済センサス‐活動調査 卸売業，小売業に関する集計
産業編（市区町村表）第1表・第2表。https://www.e-stat.go.jp/statistics/00200553

## 商業集積地区（商店街）別の表（shopping_district）

立地環境特性編の、商業集積地区（商店街）12,535地区ごとの表です。商業集積地区は、小売業・飲食店・
サービス業の事業所が近接して30店舗以上集まる商店街を概ね1つずつ区切った地区で、駅ビルや
ショッピングセンターも原則1地区になります。1地区につき小売業計（I2）・飲食サービス業計（M2）・
生活関連サービス業計（N）の3行で、地区の行（district_level = 'district'）のほかに、全国・都道府県・
市区町村・区ごとの計の行があります。地区のある市区町村は1,334です。

地区の位置（座標・境界・町丁目）は原典にありません。地区は名前（銀座地域、新宿駅西口など）と、
それが計上された市区町村（area）だけで特定します。同じ名前の地区が別の市区町村にもあります
（本町商店街は94地区）。

全国の地区の小売業は事業所数 259,039・売上（収入）金額 49兆8,238億円・売場面積 54,794,283m2 です。
小売業の金額は年間商品販売額ではなく売上（収入）金額で、従業者数は臨時雇用者を含むので、
retail_municipality の値とは比べられません。

事業所数・大規模小売店舗内事業所数・従業者数は秘匿が無く、地区の和が市区町村の計に一致します。
売上（収入）金額と売場面積は秘匿の地区が NULL になります（事業所のある地区のうち、小売業で4.9%、
飲食サービス業で19.8%、生活関連サービス業で23.5%）。売場面積は、事業所があっても「-」（該当数字なし）の
地区も NULL になります。市区町村の計はほとんど秘匿されないので、
市区町村ごとに比べるときは計の行を使います。

```sql
-- 小売業の売上（収入）金額が大きい商業集積地区
SELECT district_code, district_name, area, district_type,
       establishments, sales_million_yen, floor_area_m2
FROM e_stat.economic_census.shopping_district
WHERE district_level = 'district' AND industry_code = 'I2'
ORDER BY sales_million_yen DESC NULLS LAST
LIMIT 10;
```

この表は毎日の更新（CI）では e-Stat から取らず、手元で1回だけ取り込んでいます
（下の「手元で1回だけ取り込む統計表」）。

出典: 総務省・経済産業省 令和3年経済センサス‐活動調査 立地環境特性編
商業集積地区（商店街）別の表。https://www.e-stat.go.jp/statistics/00200553

## 補足: economic_census.establishment_mesh_1km

平成28年経済センサス‐活動調査の地域メッシュ統計のうち、1kmメッシュ（3次メッシュ）別の産業大分類別の事業所数と従業者数を縦持ちで収録する。
事業所の所在地で数えるので、どこで人が働いているか（従業地ベース）の分布になる。
cat01 に産業と「事業所数／従業者数」の別が入る。
0010 が全産業の事業所数、0200 が全産業の従業者数で、全産業は A～R（S 公務を除く）。
経済センサスのメッシュ統計は、e-Stat の API には平成28年までしか登録されていない。

2021年6月1日現在、年間商品販売額は2020年1年間。

売場面積（136,952,597m2）は総括表と一致する。

特別区は 'ward' に入り、その親「特別区部」（13100）が'municipality' に立つ。

## 補足: economic_census.shopping_district

2021年6月1日現在、売上（収入）金額は2020年1年間。
地区のほかに、全国・都道府県・市区町村・区ごとの商業集積地区の計の行もある。
商業集積地区は商店街を形成している地区で、概ね1つの商店街（小売業・飲食店・サービス業の事業所が近接して30店舗以上集積しているもの）を1地区とする。
ショッピングセンターや駅ビルも原則として1地区になる。
district_type_code は立地環境特性の細分類（11 駅周辺型・12 市街地型・13 住宅地背景型・14 ロードサイド型・15 その他）。
地区は名前（銀座地域・新宿駅西口・本町商店街など）と、それが計上された市区町村（area）でしか特定できない。
同じ名前の地区がほかの市区町村にもある（本町商店街は94地区）ので、名前で結合するときは area もそろえる。
市区町村を跨ぐ地区も、どれか1つの市区町村に計上されている。
全国の地区の計は、小売業が事業所数 259,039・従業者数 2,316,334・売上（収入）金額 49兆8,238億円・売場面積 54,794,283m2、飲食サービス業が事業所数 188,254・売上（収入）金額 5兆7,371億円、生活関連サービス業が事業所数 93,803・売上（収入）金額2兆5,367億円。
立地環境特性編の小売業全体（事業所数 755,015・売上（収入）金額 146兆5,317億円）のうち、商業集積地区にある分を表す。
district_level が'district' の行だけ、または 'municipality' の行だけを足すと全国の計に一致する（事業所数・従業者数）。
'ward' は政令指定都市と特別区部の内訳で、その地区は区の下に入る。
商業集積地区が1つも無い市区町村は行が無い（地区のある市区町村は1,334）。
子の和は親の計に一致する。
売上（収入）金額と売場面積は、集計対象の事業所が1か2の地区と、差し引きでそれが分かる地区が秘匿（「x」）されて NULL になる。
事業所のある地区のうち売上が NULL なのは、小売業 605/12,473（4.9%）・飲食サービス業 2,357/11,875（19.8%）・生活関連サービス業 2,787/11,840（23.5%）。
小売業の売場面積が NULL の地区は 996。
売場面積は事業所があっても「-」（該当数字なし）の地区があり、これも秘匿と区別できずに NULL で入る（996 のうち少なくとも 444 は、計から分かっている地区を引くと 0 になる）。
市区町村の計は秘匿がほとんど無いので、市区町村ごとに比べるときは計の行を使う。
売上（収入）金額は原典が地区ごとに丸めているため、地区の和が計と最大で（地区数 + 1）× 0.5 百万円ずれる。
