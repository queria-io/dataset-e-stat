# 経済産業省企業活動基本調査 産業別・都道府県別・資本金規模別の財務、研究開発、外資系企業、子会社

| テーブル | 内容 | 主なカラム |
|---------|------|-----------|
| industry_finance | 産業別の企業数・事業所数・従業者数・資産・負債及び純資産・売上高・利益・付加価値額・子会社数（2005〜2024年度） | fiscal_year / industry_code / measure / unit / value |
| prefecture_finance | 都道府県別・産業別の同じ項目（2009〜2024年度） | fiscal_year / industry_code / area / measure / unit / value |
| capital_size_finance | 資本金規模別・産業別の資産・負債及び純資産・損益・費用の内訳（2009〜2024年度） | fiscal_year / industry_code / capital_size_code / measure / unit / value |
| research_development | 産業別の研究開発費・受託研究費・研究開発投資・能力開発費（2009〜2024年度） | fiscal_year / industry_code / measure / unit / value |

経済産業省の企業活動基本調査（確報）です。従業者50人以上かつ資本金または出資金3,000万円以上の、
鉱業、製造業、卸売業、小売業、一部のサービス業などの企業を対象に、毎年、前年度の実績を調べます。
2010〜2025年の調査（2009〜2024年度実績）の表を収録しています。外資系企業の表は2015年調査から
（2014年度実績から）です。総括表（industry_finance）は各調査が過去5年度の値も持つので、2005年度から
あります。同じ年度は最も新しい調査の値を使います。2019年以前の調査では、後の調査で過去の年度の値が
直っていることがあります（2008年度の合計の当期純利益は、2010年調査と2011年調査で違います）。

2019年以前の調査の表は、産業の大分類にコードが付いていません。産業名を2020年以降の表のコードに
当てています。測定項目は表頭の並び順で2025年調査の項目に当てています。

## 産業と測定項目

`industry_code` には、総合計・合計・大分類・中分類・小分類が同じ列に並びます。企業数では次の関係が
ちょうど成り立ちます。

- 合計（`000`）= 大分類（`C`・`E`・`F`・`G`・`I1`・`I2`・`J1`・`K1`・`L`・`M`・`N`・`O`・`R1`）の和
- 総合計 = 合計（`000`）+ サービス業（その他のサービス業）（`R2`）+ その他の産業（`Z`）

`measure` は「資産_流動資産」のように上位の項目と「_」でつないだ名称で、計と内訳が同じ列に並びます。
単位は `unit` にあり、表によって社・事業所・人・百万円・％が混ざります。

```sql
-- 2024年度 大分類別の売上高
SELECT industry_code, industry_name, round(value / 1e6, 1) AS sales_trillion_yen
FROM e_stat.enterprise_activity.industry_finance
WHERE fiscal_year = 2024 AND measure = '売上高'
  AND industry_code IN ('C', 'E', 'F', 'G', 'I1', 'I2', 'J1', 'K1', 'L', 'M', 'N', 'O', 'R1')
ORDER BY value DESC;
```

## 都道府県別

prefecture_finance は企業を本社のある都道府県に数えた値です。47都道府県の企業数の和は全国に一致します。
事業所数も一致しますが、秘匿で空欄の県がある年度（2013年度）は和が全国より小さくなります。売上高などは秘匿の分だけ和が全国より小さくなる年度があります。

## 資本金規模別

capital_size_finance は第3-1表（資産・負債及び純資産）と第4表（損益・費用の内訳）を積んだものです。
企業数・売上高・経常利益は両方の表にあり、第3-1表の値を使います。秘匿の範囲が表で一部違うので、
第3-1表が空欄のセルは第4表の値で埋めています。資本金規模は計（`00`）と
8区分で、企業数では8区分の和が計に一致します。

## 研究開発

research_development の企業数（`研究開発_企業数` など）は研究開発・研究開発投資・能力開発を行った
企業の数です。産業の企業数全体ではありません。

## 子会社・関連会社

subsidiary_count の子会社の全業種の行は、親会社の産業が総合計の行では `subsidiary_industry_code` =
`総合計`、それ以外の産業では `000`（合計）です。
